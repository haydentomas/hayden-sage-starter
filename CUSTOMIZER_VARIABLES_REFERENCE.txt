================================================================================
HAYDEN SAGE STARTER - CUSTOMIZER VARIABLES REFERENCE
================================================================================

This file contains a complete map of all available CSS variables and their
default values that are generated from the WordPress Customizer settings.

Use these variables when building custom blocks to ensure consistent styling
with the theme's design system.

================================================================================
SECTION 1: COLOR VARIABLES
================================================================================

---
BRAND COLORS (Primary/Secondary)
---
--color-primary          Default: #f97316 (Orange)
                         Customizer: Theme Palette > Primary
                         Usage: Main brand color, buttons, accents, headings

--color-surface          Default: #FFFAF8 (Cream/Off-white)
                         Customizer: Theme Palette > Background
                         Usage: Main page background, card backgrounds

--color-headings         Default: #f97316 (Orange)
                         Customizer: Theme Palette > Heading text
                         Usage: H1, H2, H3, heading elements

--color-body             Default: #111111 (Near-black)
                         Customizer: Theme Palette > Body text
                         Usage: Paragraph text, body copy, default text color

---
FOOTER COLORS
---
--color-footer           Default: #020617 (Dark navy)
                         Customizer: Theme Palette > Footer > Footer background
                         Usage: Footer section background color

--color-footer-text      Default: #94a3b8 (Slate gray)
                         Customizer: Theme Palette > Footer > Legal text
                         Usage: Copyright/legal text at bottom of footer

--color-footer-widget-heading  Default: #f97316 (Orange)
                              Customizer: Theme Palette > Footer > Footer widget title
                              Usage: Footer widget titles/headings

--color-footer-widget-text     Default: #ffffff (White)
                              Customizer: Theme Palette > Footer > Footer widget text
                              Usage: Footer widget body text

--color-footer-widget-link     Default: #f97316 (Orange)
                              Customizer: Theme Palette > Footer > Footer widget link
                              Usage: Links within footer widgets

---
WIDGET COLORS (Sidebar widgets, global)
---
--color-widget-bg        Default: #000000 (Black)
                         Customizer: Theme Palette > Widgets > Widget background
                         Usage: Sidebar widget container background

--color-widget-heading   Default: #f97316 (Orange)
                         Customizer: Theme Palette > Widgets > Widget title
                         Usage: Sidebar widget titles

--color-widget-text      Default: #ffffff (White)
                         Customizer: Theme Palette > Widgets > Widget text
                         Usage: Sidebar widget body text

--color-widget-link      Default: #f97316 (Orange)
                         Customizer: Theme Palette > Widgets > Widget link
                         Usage: Links within sidebar widgets

--color-surface-soft     Default: #000000 (Alias for widget bg)
                         Usage: Alternative name for widget background

---
CARD COLORS (Blog cards, portfolio cards, content cards)
---
--card-bg                Default: #000000 (Black)
                         Customizer: Cards & Grid > Card Background
                         Usage: Blog/portfolio card background

--card-heading           Default: #f97316 (Orange)
                         Customizer: Cards & Grid > Card Heading
                         Usage: Titles within cards

--card-text              Default: #ffffff (White)
                         Customizer: Cards & Grid > Card Text
                         Usage: Main text within cards

--card-text-muted        Default: #e5e5e5 (Light gray)
                         Customizer: Cards & Grid > Card Muted Text
                         Usage: Secondary text, metadata, excerpts

---
NAVIGATION COLORS
---
--color-nav-link         Default: #111111 (Near-black)
                         Customizer: Theme Palette > Navigation > Nav parent link
                         Usage: Main navigation link text color

--color-nav-link-hover   Default: #f97316 (Orange)
                         Customizer: Theme Palette > Navigation > Nav link hover/active
                         Usage: Navigation link hover/active state

--color-nav-sub-bg       Default: #020617 (Dark navy)
                         Customizer: Theme Palette > Navigation > Dropdown background
                         Usage: Dropdown menu background color

--color-nav-sub-link     Default: #f97316 (Orange)
                         Customizer: Theme Palette > Navigation > Dropdown link
                         Usage: Dropdown menu link text

--color-nav-sub-hover-bg Default: #3b1d08 (Dark brown)
                         Customizer: Theme Palette > Navigation > Dropdown link hover background
                         Usage: Dropdown item hover background

--color-nav-toggle       Calculated from --color-surface
                         Usage: Mobile menu toggle icon color (auto-calculated for contrast)

SECTION 4: SPACING VARIABLES
================================================================================

---
VERTICAL SPACING (Between sections/blocks)
---
--section-space-mobile   Default: 6rem (based on medium preset)
--section-space-desktop  Default: 6rem (based on medium preset)
                         Customizer: Block Spacing > Vertical spacing scale
                         Options: 
                           - none: 0
                           - small: 4rem
                           - medium: 6rem
                           - large: 8rem
                         Usage: Margin-top/bottom between major sections

---
BLOCK INNER SPACING (Padding within blocks)
---
--block-padding          Default: 4rem (based on default preset)
                         Customizer: Block Spacing > Block inner spacing
                         Options:
                           - compact: 3rem (desktop), 1.75rem (mobile)
                           - default: 4rem (desktop), 2.5rem (mobile)
                           - spacious: 6rem (desktop), 3.5rem (mobile)
                         Usage: Internal padding for hero, cards, content areas

SECTION 6: USAGE EXAMPLES
================================================================================

---
EXAMPLE 1: Creating a Card Block
---
.card {
  background-color: var(--card-bg);
  border-radius: var(--radius-md);
  padding: var(--block-padding);
  color: var(--card-text);
}

.card__title {
  color: var(--card-heading);
  font-size: var(--h3-font-size-desktop);
  margin-bottom: 0.5rem;
}

.card__excerpt {
  color: var(--card-text-muted);
  font-size: var(--text-base);
}

---
EXAMPLE 2: Creating a Hero Section
---
.hero {
  max-width: var(--site-max-width);
  margin: var(--section-space-desktop) auto;
  padding: 0 2rem;
  background-color: var(--color-surface);
}

.hero__title {
  color: var(--color-headings);
  font-size: var(--h1-font-size-desktop);
}

---
EXAMPLE 3: Creating a Button
---
.btn {
  background-color: var(--color-primary);
  color: var(--color-surface);
  border-radius: var(--radius-md);
  padding: 0.75rem 1.5rem;
  font-size: var(--text-base);
  border: none;
}

.btn:hover {
  opacity: 0.9;
}

---
EXAMPLE 4: Creating a Widget Box
---
.widget {
  background-color: var(--color-widget-bg);
  padding: var(--block-padding);
  border-radius: var(--radius-lg);
}

.widget__title {
  color: var(--color-widget-heading);
  font-size: var(--h3-font-size-desktop);
  margin-bottom: 1rem;
}

.widget__link {
  color: var(--color-widget-link);
  text-decoration: none;
}

.widget__link:hover {
  opacity: 0.8;
}

================================================================================
NOTES FOR DEVELOPERS
================================================================================

1. RESPONSIVE TYPOGRAPHY
   Use the -mobile and -desktop variants to apply different sizes on mobile
   and desktop. Media queries are your responsibility in block CSS.

2. COLOR CALCULATIONS
   The --color-nav-toggle variable is automatically calculated to ensure
   contrast with the surface color. Don't hardcode this value.

3. SPACING FLEXIBILITY
   The --block-padding variable changes globally. Blocks don't need
   media-specific padding variables; this is already handled.

4. RADIUS CONSISTENCY
   All rounded elements should use the radius variables, not hardcoded values.
   This ensures the theme maintains consistency when users change the
   Border Radius style.

5. CSS CUSTOM PROPERTIES FALLBACKS
   Always include fallback values in case a variable isn't set:
   color: var(--color-primary, #f97316);

6. OUTPUTTING VARIABLES IN BLOCKS
   The customizer automatically outputs these as CSS custom properties in
   wp_head. No additional PHP is needed to access them in block CSS files.

7. CONTAINER CONSTRAINTS
   Use --site-max-width with flex/grid and add padding (gutters) as needed.
   Don't assume the full viewport width without padding.
